# コミュニティ サポート ハブ

[Prestomedia](https://prestomedia.com/ja) アプリケーションの公式公開コミュニティ サポート フォーラムへようこそ！

このスペースは、ユーザー同士の交流、機能のリクエスト、全般的な Q&A のための場所です。*こちらは公開コミュニティ フォーラム* である点にご注意ください。



## 📱 アプリケーションを選択してください

質問、問題の報告、アイデアの提案を行うには、以下の該当するアプリのディスカッション カテゴリをクリックしてください：

* 📝 [**Free Text Editor**](https://github.com/PrestomediaLLC/community-ja/discussions/categories/free-text-editor-com)
* 📊 [**Pro Diagrams**](https://github.com/PrestomediaLLC/community-ja/discussions/categories/prodiagrams-com) (準備中)
* 📊 [**Free Diagrams**](https://github.com/PrestomediaLLC/community-ja/discussions/categories/freediagrams-com) (準備中)
* 📊 [**Team Matcher**](https://github.com/PrestomediaLLC/community-ja/discussions/categories/team-matcher-com) (準備中)

*(カテゴリ内で **「New discussion」** をクリックすると、専用の投稿フォームが表示されます。)*



## 📋 コミュニティ ガイドライン

投稿する前に、以下の点をご確認ください：

1. **事前に検索する：** お使いのアプリのカテゴリ内に既存のディスカッションがないか確認してください。すでに質問やリクエストへの回答が存在する場合があります。
2. **プライバシーを守る：** **個人情報**、メールアドレス、パスワード、ライセンスキー、機密性の高い財務データを投稿しないでください。すべての投稿は完全に公開されます。
3. **お互いを尊重する：** 他のコミュニティ メンバーには思いやりを持って接してください。親切で建設的な議論が、全員にとってより良いアプリの開発につながります！
